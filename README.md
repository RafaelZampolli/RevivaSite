# ReViva — site institucional

Site institucional responsivo da ReViva, uma HealthTech brasileira que explora Realidade Virtual, gamificação e acompanhamento de desempenho como apoio à reabilitação.

## Páginas

- Início
- A ReViva
- Solução
- Tecnologia
- Para profissionais
- Para instituições
- Contato
- Página 404 personalizada

## Executar localmente

```bash
pnpm install
pnpm dev
```

Para gerar uma versão de produção:

```bash
pnpm build
```

O projeto usa React, TypeScript e Vite, com componentes reutilizáveis e estilos responsivos em `src/styles/global.css`.
